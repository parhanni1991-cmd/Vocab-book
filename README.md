# 소설가의 어휘 사전 — 한자어·고유어 (초안)

소설을 쓰는 데 필요한 어휘력을 기르기 위한 개인 사전이다.
일상 대화에서는 잘 쓰지 않지만 소설과 산문에서 자주 보이는 말을 모았다. 뜻을 정확히 알면 문장의 결이 달라지는 말들이다.
**한자어 사전**과 **고유어 사전** 두 권으로 나누었고, 두 사전 모두 집필 상황에 따른 **주제별** 6개 장으로 구성했다.

## 표제어 선정 기준

- 소설·수필에서 자주 쓰이고 묘사와 서술에 바로 쓸 수 있는 말을 골랐다.
- 누구나 아는 기초어(사랑, 하늘, 기쁘다 등)는 넣지 않았다.
- 사어, 지나치게 희귀한 말, 지역 방언은 넣지 않았다. 표준어만 실었다.
- 한자어와 고유어를 **대응어**로 서로 이었다. 예: 적막 ↔ 괴괴하다, 초췌하다 ↔ 핼쑥하다.
- 각 장 안에서는 표제어를 가나다순으로 늘어놓았다.

## 앱으로 보기

`app/` 폴더에 사전을 찾아보는 웹앱이 있다. 휴대폰과 PC 브라우저에서 열 수 있다.

- **기능**: 한자어/고유어 구분과 주제별 보기, 검색(표제어·한자·뜻·예문·유의어·대응어), 초성 검색(예: `ㄱㄱㅎㄷ` → 괴괴하다), 대응어를 눌러 해당 단어로 이동하기, 오늘의 단어.
- **앱처럼 쓰기**: 휴대폰 브라우저 메뉴의 '홈 화면에 추가'를 누르면 아이콘이 생긴다. 한 번 연 뒤에는 오프라인에서도 열린다.
- **배포 주소**: https://parhanni1991-cmd.github.io/Vocab-book/ (GitHub Pages)
  - 처음 한 번은 저장소 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 바꿔야 한다.
  - 이후에는 저장소의 기본 브랜치에 push할 때마다 자동으로 배포된다(`.github/workflows/pages.yml`).
- **내 컴퓨터에서 열기**: `python3 -m http.server -d app` 실행 후 http://localhost:8000 접속.

### Claude에게 묻기 (AI 질문)

단어 카드를 펼친 뒤 **✦ Claude에게 묻기**를 누르거나, 오른쪽 아래 떠 있는 버튼을 누르면 대화창이 열린다. 뉘앙스 비교, 예문 더 보기, 내 문장 다듬기, 퀴즈를 바로 고를 수 있고 자유롭게 물어도 된다.

- **필요한 것**: Claude API 키. Claude Console(platform.claude.com)의 API Keys에서 만든다. Max 플랜의 월간 API 크레딧을 그 Console 조직에 연결해 두면 사용 요금이 크레딧에서 차감된다.
- **키 보관**: 처음 열 때 나오는 설정 화면에 키를 넣는다. 키는 그 기기의 브라우저에만 저장되고 저장소에는 올라가지 않는다. 브라우저에서 Claude API를 직접 부르는 방식이라 키를 아는 사람은 누구나 그 키로 요청할 수 있으므로, 공용 기기에서는 '키 지우기'를 누른다.
- **모델**: 기본은 Claude Opus 5.5이고, 설정에서 Claude Haiku 5.5(빠르고 저렴)로 바꿀 수 있다. 답마다 아래에 입력·출력 토큰 수가 표시된다.
- **노력 수준**: Claude가 답하기 전에 얼마나 깊이 생각할지 정한다. 기본은 '낮음'(빠르고 저렴)이고, 설정에서 '보통'이나 '높음'으로 올릴 수 있다. 높을수록 답이 깊어지는 대신 느리고 비싸진다(생각에 쓴 토큰도 출력 요금에 포함). 바꾸면 다음 질문부터 적용된다.
- **보내는 내용**: 질문, 지금 보는 단어와 질문에 나온 표제어의 사전 항목, 사전 표제어 목록. 사전 전체를 매번 보내지 않아 비용이 적다.
- **오프라인**: AI 질문은 인터넷이 있어야 된다. 사전 보기·검색은 오프라인에서도 된다.
- **SDK**: `app/vendor/anthropic-sdk.js`는 Anthropic 공식 TypeScript SDK를 브라우저용으로 묶은 파일이다. 버전을 올리려면 `scripts/vendor_sdk.sh <버전>`을 실행한다.

### 사전을 고친 뒤

앱은 Markdown 파일이 아니라 거기서 만든 `app/words.json`을 읽는다. 사전 파일을 고쳤다면 다음을 실행하고 함께 커밋한다.

```bash
python3 scripts/build_data.py          # app/words.json 다시 만들기
python3 scripts/build_data.py --check  # 최신인지 확인
```

## 항목 읽는 법 (범례)

### 한자어 항목

```markdown
### 적막(寂寞) 〔명사〕
- **훈음**: 寂 고요할 적 · 寞 쓸쓸할 막
- **뜻**: ① 고요하고 쓸쓸함. ② 의지할 데 없이 외로움.
- **예문**: 그가 떠난 뒤, 집 안에는 시계 초침 소리만이 적막을 갈랐다.
- **유의어**: 정적, 고적
- **고유어 대응**: 괴괴하다, 쓸쓸하다
```

- **표제어(한자) 〔품사〕**: '-하다'가 붙어 주로 형용사·동사로 쓰이는 말은 '-하다' 꼴로 올렸다.
- **훈음**: 글자마다 대표 훈(뜻)과 음을 적었다. 두음 법칙으로 소리가 바뀌는 글자는 본음 뒤에 괄호로 실제 소리를 적었다. 예: 憐 불쌍히 여길 련(연).
- **뜻**: 표준국어대사전의 뜻풀이를 따랐다. 뜻이 여럿인 말은 사전의 번호 순서(①②③…)대로 적었다. 전문 분야 뜻처럼 소설에 잘 쓰이지 않는 뜻은 뺐고, 이때는 '(사전의 뜻 중 일부)'로 표시했다.
- **예문**: 소설 문장처럼 직접 지은 예문이다.
- **유의어**: 뜻이 비슷한 말이다. 완전한 동의어가 아니면 관련어도 함께 적었다.
- **고유어 대응**: 바꾸어 쓸 수 있는 고유어다. 관용 표현도 포함했다.

### 고유어 항목

```markdown
### 괴괴하다 〔형용사〕
- **뜻**: 쓸쓸한 느낌이 들 정도로 아주 고요하다.
- **예문**: 인적이 끊긴 골목은 괴괴하기만 했다.
- **유의어**: 고요하다, 호젓하다
- **한자어 대응**: 적막하다, 적요하다
```

- 고유어 항목에는 훈음 대신 **한자어 대응**이 들어간다. 마땅한 대응어가 없는 말은 이 칸을 비워 두었다.

## 활용 팁

1. **대응어를 함께 익힌다.** 같은 장면을 한자어로 쓰면 건조하고 단단해지고, 고유어로 쓰면 부드럽고 감각적으로 바뀐다. 예: "적막이 내려앉았다" / "괴괴했다".
2. **예문을 내 문장으로 고쳐 쓴다.** 예문 아래에 자기 소설의 인물과 배경으로 한 문장씩 더 써 보면 오래 기억에 남는다.
3. **쓰다가 막힐 때 주제별로 찾는다.** 인물의 얼굴을 묘사해야 하면 '2. 인물·외모·성격'을, 해 질 녘 장면이면 '5. 시간·계절'을 연다.

## 사전 대조 결과 (2026년 10월)

표제어 207개 전부를 표준국어대사전(stdict.korean.go.kr)과 대조했다. 207개 모두 사전에 실린 표준어임을 확인했고, 품사와 원어(한자)와 뜻풀이를 사전에 맞게 고쳤다.

**주요 수정 사항**
- **격분**: 한자를 激憤에서 **激忿**으로 고쳤다. 사전에서 激憤의 첫 뜻은 '분발하도록 격려함'이다.
- **걸걸하다**: 둘째 뜻을 '성질이나 행동이 조심스럽지 못하고 거칠다'로 고쳤다. 초안의 '쾌활하고 시원시원하다'는 별개 낱말인 걸걸(傑傑)하다의 뜻이었다.
- **내닫다**, **다그치다**, **북받치다**, **향수**: 사전에 없는 뜻을 지우고 사전의 뜻으로 바꿨다.
- **단아하다**: '단정하고 우아하다'를 '단정하고 아담하다'로 고쳤다.
- **음울하다**: 사전에는 뜻이 하나다('기분이나 분위기 따위가 음침하고 우울하다').
- **는개**: '안개보다는'을 '안개비보다는 조금 굵고'로 고쳤다.
- **안도**: 유의어 '방심'을 '방념'으로 고쳤다. 방심은 뜻이 다르다.
- **창백하다, 교교하다, 청명하다, 몽롱하다, 휘영청** 등은 소설에 쓸모 있는 뜻(달빛, 불빛, 고요함 따위)을 사전에서 찾아 보탰다.

**확인된 사항**
- [x] **괴팍하다**: 원어는 乖愎▽으로 사전에 실려 있다.
- [x] **바람꽃**: '큰 바람이 일어나려고 할 때 먼 산에 구름같이 끼는 뽀얀 기운'이라는 뜻의 표제어(바람꽃1)가 있다.
- [x] **윤슬**: 원어 표시 없이 실려 있다. 고유어인지는 이견이 있다.
- [x] **왁자하다**: 형용사와 동사 두 가지 품사로 실려 있다. 이 어휘 사전에는 형용사 뜻을 실었다.

**남은 과제**
- [ ] 유의어와 대응어 가운데 사전의 '비슷한말'로 확인되지 않은 것(직접 고른 말)은 쓰임새를 한 번 더 살핀다.
- [ ] 한자 훈음은 대표 훈 하나만 적었다. 단어 속에서 다른 뜻으로 쓰인 글자는 '참고'에 따로 밝혔다. 예: 朔 = 북쪽, 諦 = 살피다.

## 앞으로의 확장 계획 (제안)

- 주제를 추가한다: 소리·의성어, 몸짓·표정, 음식·냄새, 관계·사회.

- 현대 소설에서 실제로 쓰인 문장을 용례로 덧붙인다.
