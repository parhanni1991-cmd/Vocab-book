API 키 설정

Claude Console(platform.claude.com)의 API Keys에서 키를 만들어 붙여 넣으세요. Max 플랜의 월간 API 크레딧을 그 Console 조직에 연결해 두면 사용 요금이 크레딧에서 차감됩니다.

사용액은 이 기기에서 보낸 질문의 토큰 수로 어림한 값이며 매달 1일에 0이 됩니다. 실제 크레딧 잔액과 결제 주기는 Console의 Billing에서 확인하세요. 크레딧이 바닥나면 Claude API가 요청을 거절하므로, 그때도 답은 멈춥니다.

키는 이 기기의 브라우저에만 저장되고, Claude API(api.anthropic.com)에 요청할 때만 쓰입니다. 공용 기기에서는 사용 뒤 '키 지우기'를 눌러 주세요.
